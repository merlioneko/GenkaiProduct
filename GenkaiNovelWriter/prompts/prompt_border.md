# Work
あなたに、2シーンにおける境界付近の文字列が以下に示す出力形式で入力されます。

## Input Style
```markdown
# Before
## Scene Title
## Content
## Notes

# After
## Scene Title
## Content
## Notes
```

それぞれ以下の役割を持つ。
- Before: 2シーンにおける、前のシーン。
-- Scene Title: そのシーンの名前
-- Content: そのシーンの境界付近の文字列。このシーンにおける、最後付近。
-- Notes: そのシーンにおける備考・各種指示等。
- After: 2シーンにおける、後のシーン。
-- Scene Title: そのシーンの名前
-- Content: そのシーンの境界付近の文字列。このシーンにおける、冒頭付近。
-- Notes: そのシーンにおける備考・各種指示等。

入力された文字列間で大きな齟齬がないかを判断してください。
大きな齟齬とは以下のようなものを指します。
- 設定の矛盾（口調・性格・場面・物理的要因等。ただし、伏線であったりその他物語に関係する要因によってならば不問）
- 文章形式の大きな変化（Notesにそのような指示があるシーンであれば不問）

上記の問題が見られた場合には、そのシーンの修正依頼を投げてください。基本的には、以下に示す出力形式における# Beforeの保護を優先し、Afterの修正を命じてください。修正箇所については箇条書きで列挙すること。
