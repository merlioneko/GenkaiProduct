# プロジェクト指針

- 仕様は SPEC.md を唯一の正とする。矛盾があれば実装せず質問する。
- 作業計画は MILESTONES.md に従う。現在のマイルストーン: M4(未着手)。M2 は 2026-10-13 に完了承認済み。M3 は 2026-10-19 の実装・実機検証記録により完了、U5 は D42 として確定済み。範囲外の変更は提案のみ行い、実装しない。
- 1コミット1目的。リファクタリングと機能実装を混在させない。
- SPEC.md の「未確定事項」に依存するコードは書かない。着手条件を満たさないマイルストーンには着手しない。
- `.env/` 配下のファイル(APIキー等)を読み取って出力・コミットしない。
- 品質の評価はローカルバックエンドの出力でのみ行う。OpenRouter の出力を品質判断の根拠にしない。
- Concept の保存形式は固定見出しの Markdown で確定済み(D41、旧U10)。生成時の形式とは別の判断として扱う。
- M4 着手時は MILESTONES.md「M3」の完了記録と「M4: Check」、SPEC.md「M3 実装・実機検証の記録」を読む。D39 は実装済みだが、Qwen の再ロード・生成を伴う通し切替は未検証。本文の要素保持・名前の揺れ・ビート由来のメタ表現・物理動作の課題を検査へ引き継ぐ。M5 の比較には無編集の出力を新規採取する。
