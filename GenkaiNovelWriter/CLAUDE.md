# プロジェクト指針

- 仕様は SPEC.md を唯一の正とする。矛盾があれば実装せず質問する。
- 作業計画は MILESTONES.md に従う。現在のマイルストーン: M3(M2 は 2026-10-13 に完了承認済み。M3 の実装・実機実行は未着手)。範囲外の変更は提案のみ行い、実装しない。

- 品質の評価はローカルバックエンドの出力でのみ行う。OpenRouter の出力を品質判断の根拠にしない。
- Concept の保存形式は固定見出しの Markdown で確定済み(D41、旧U10)。生成時の形式とは別の判断として扱う。
- M3 着手時は MILESTONES.md「開始時の確認と引き継ぎ」と SPEC.md「M2 実機検証の記録と完了承認」を読む。Python 実行環境の確認、モデル切り替え時の明示的なアンロード(D39)、本文への指示文の流用確認を含む。
